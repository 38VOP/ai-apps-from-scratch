## Нічний пакет (22.08.2026, координатор самостійно)

**П.1 — margin-фікс SourcesPanel.jsx: коміту НЕ потребував.**
Перевірено: marginTop:16/marginBottom:16 уже присутні в main (рядки 206-207) — фікс потрапив у код разом з правками індикатора версії. `git diff HEAD` по файлу порожній, `git diff stash@{1} HEAD` не показує розбіжностей по margin. Guardian припускав саме це. Застарілі stash-записи прибрано (залишено stash@{0} — містить catalog.db, не чіпав через FREEZE).

**П.2 — чіткіші контури блоків: commit 10731c8.**
Причина слабких контурів: `--border-color: rgba(255,255,255,0.08)` — 8% білого на темному фоні. Правка однієї змінної в index.css (0.08 → 0.16, а також --border-hover 0.4 → 0.55) підсилила контури 41 елемента одночасно, без правки кожного місця окремо. Перевірено в браузері через getComputedStyle: model-card, sidebar (border-right), app-header (border-bottom) — усі три віддають rgba(255,255,255,0.16).

**П.3 — пошук у шапці: commit e32a6ce.**
Знахідка: поле пошуку не потрібно було "переносити" — його не існувало в JSX взагалі, хоча CSS-класи .search-box/.search-icon/.search-input були готові в index.css (рядки 156-187). Створено поле в .header-right зліва від кошика, під умовою activeTab === 'catalog'. Перевірено в браузері: search_left_of_cart=true (x=1180 проти x=1516). Фільтрація підтверджена end-to-end через API: 6483 моделі без пошуку → 55 при search=DECO; у браузері всі назви карток після введення містять DECO/Decoration/Decorative.

**ІНЦИДЕНТ (розв'язано): git push зависав на 10+ хвилин.**
Симптом: push/fetch висіли безкінечно (зафіксовано 567 с без прогресу), при тому що мережа справна — curl до github.com відповідав за 0.2 с з кодом 200. Причина знайдена через GIT_TRACE=1: `run_command: 'git credential-manager get'` — глобальний `credential.helper=manager` (Git Credential Manager) намагався відкрити GUI-вікно авторизації. Оскільки власник не за компом, вікно ніхто не закривав → нескінченне очікування. Другий helper (`store`) з готовим ~/.git-credentials працює коректно.
Виправлення: у локальному конфізі репозиторію закріплено `credential.helper=store` + `credential.interactive=false` — локальний конфіг перебиває глобальний GCM. Після цього push пройшов за секунди (beb6825..e32a6ce), fetch теж миттєвий. Жодних креденшлів не переглядав і не змінював.
Побічна знахідка (НЕ виправляв, потребує рішення): `.git` роздутий до 469 МБ через історично закомічені venv/, dist/ і catalog.db. Це сповільнює будь-яку git-операцію, бо кожен push перепаковує величезний репозиторій. Очищення історії — деструктивна операція (переписування історії, ризик для інших агентів), тому чекає на явне рішення.

**Пункти 4+ (блок "Налаштування", пагінація) — НЕ починав** за прямою вказівкою Guardian: складніші задачі, потребують живого діалогу.
